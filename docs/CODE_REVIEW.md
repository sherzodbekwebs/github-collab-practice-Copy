# Code Review Guide

## Purpose

Code reviews help maintain code quality, security, and readability.

## Review Checklist

- [ ] The code solves the stated problem.
- [ ] Changes are focused and easy to understand.
- [ ] Naming and formatting are consistent.
- [ ] Errors and edge cases are handled.
- [ ] No secrets or credentials are exposed.
- [ ] Tests are included where appropriate.
- [ ] Documentation is updated if needed.

## Review Process

1. Read the Pull Request description.
2. Inspect the changed files.
3. Check tests and potential regressions.
4. Leave specific, constructive feedback.
5. Approve only when the changes are ready.

## Feedback Guidelines

Explain why a change is needed and suggest an actionable improvement.
