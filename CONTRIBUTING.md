# Contributing Guide

Thank you for contributing!

## Development Workflow

1. Create a new branch from `main`.
2. Make a focused improvement.
3. Test your changes.
4. Open a Pull Request with a clear description.
5. Review feedback and update your branch if needed.

## Pull Request Checklist

- [ ] Changes have a clear purpose.
- [ ] Documentation is updated where necessary.
- [ ] Existing functionality is not broken.
- [ ] The Pull Request has a descriptive title.

## Commit Messages

Use descriptive messages such as `docs: add contributing guide` or `fix: correct validation error`.
